# Quant Data Backtest Skill

## 0. 使用边界

当用户要求“爬取数据、下载 ETF/股票数据、生成策略、做回测、用 BaoStock/AKShare、量化研究、因子回测”时，启用本 Skill。

必须遵守：

- 只使用公开、合规、低频、可缓存的数据；
- 默认优先 BaoStock、本地文件、交易所/基金公司公开文件；
- 可以使用 AKShare，但必须控制频率并缓存；
- 不绕过验证码、登录、签名、加密接口、App 私有接口、IP 封禁；
- 不抓付费数据、Level-2、会员数据；
- 不输出“确定买卖建议”或“稳赚策略”；
- 不连接券商接口、不执行实盘下单。

所有报告必须包含：

> 本项目仅用于学习、研究和回测验证，不构成投资建议。历史回测不代表未来收益。

## 1. 任务澄清与默认假设

如用户没有给出完整参数，采用以下默认值，不必反复追问：

- 标的：ETF 或 A 股指数 ETF；若没有指定，先使用用户给出的代码；没有代码则创建可配置 `universe.yaml`；
- 时间区间：默认最近 5 年；
- 频率：日线；
- 交易成本：单边 0.03% 起，可配置；
- 调仓周期：周度或月度；
- 执行规则：T 日收盘产生信号，T+1 开盘或收盘执行，默认用 T+1 收盘近似；
- 基准：等权持有、沪深 300 或用户指定 ETF；
- 数据存储：Parquet 优先，CSV 兜底。

## 2. 数据获取工作流

### 2.1 数据源优先级

1. 用户提供的本地数据；
2. BaoStock；
3. AKShare 的公开接口；
4. 交易所、基金公司、上市公司公开披露文件。

### 2.2 数据下载代码要求

每个下载函数必须：

- 有 `start_date`、`end_date`、`symbols`、`adjust`、`frequency` 参数；
- 写入本地缓存，避免重复下载；
- 支持断点续传或跳过已有文件；
- 有失败重试和间隔等待；
- 记录数据来源、下载时间、字段说明；
- 返回标准化字段：`date`, `symbol`, `open`, `high`, `low`, `close`, `volume`, `amount`，可选 `adj_factor`。

禁止：

- 多线程暴力抓取；
- 在代码里硬编码 cookie、token、账号密码；
- 把网页私有接口伪装成官方接口；
- 忽略接口报错继续生成错误数据。

## 3. 数据质量检查

生成或更新以下检查：

- 缺失值检查；
- 重复日期检查；
- 价格非正检查；
- 高低开收逻辑检查：`low <= open/close <= high`；
- 成交量/成交额异常检查；
- 停牌或无成交日期处理；
- 多标的日期对齐；
- 复权方式说明。

若发现问题，不要直接删除数据；先输出问题清单，再采用明确规则处理。

## 4. 策略生成原则

优先生成简单、可解释、低参数策略，例如：

1. 趋势跟踪：均线突破、价格高于 N 日均线；
2. 动量轮动：过去 N 日收益率排序，持有前 K 个 ETF；
3. 波动率控制：目标波动率或低波动优先；
4. 均值回归：仅在有充分解释时使用；
5. 多因子组合：动量、波动率、成交额过滤，但参数不要过多。

禁止：

- 为了提高收益而大量调参；
- 只展示最优参数，不展示稳健性；
- 使用未来收益、未来最高价/最低价、未来成分股、未来财报；
- 使用当天无法得知的数据作为当天交易信号；
- 输出“推荐买入/卖出某标的”的确定性话术。

## 5. 回测引擎要求

回测必须清楚处理：

- 初始资金；
- 持仓权重；
- 调仓日期；
- 交易价格；
- 手续费/滑点；
- 现金；
- 不能买入无价格或停牌标的；
- 信号日与执行日分离；
- 基准收益。

至少输出指标：

- 累计收益率；
- 年化收益率；
- 年化波动率；
- 最大回撤；
- 夏普比率；
- Calmar 比率；
- 胜率；
- 最大连续回撤天数；
- 换手率；
- 交易次数；
- 相对基准超额收益。

## 6. 未来函数检查

必须新增或运行测试：

- 信号日期必须小于执行日期；
- 因子计算只能使用当前日期及以前数据；
- rolling 指标必须检查 `shift(1)` 或等效延迟；
- 财务数据必须考虑披露日期，不能用报告期日期直接回填；
- 参数选择必须区分训练/验证/测试期。

如果暂时无法完全验证，必须在报告中写明限制。

## 8. 报告模板

报告应包含：

1. 研究目的；
2. 数据来源与合规说明；
3. 样本区间与标的池；
4. 数据清洗规则；
5. 策略逻辑；
6. 回测设定；
7. 绩效结果表；
8. 净值曲线与回撤曲线；
9. 稳健性检验；
10. 风险与局限；
11. 下一步改进。

报告中禁止使用：

- “必然盈利”；
- “无风险套利”；
- “稳赚”；
- “建议立即买入”；
- “保证跑赢”。

用户可以这样调用：

```text
请使用 $quant-data-backtest 技能，在本项目中搭建一个 ETF 数据下载、策略生成和回测系统。
要求：
1. 数据源优先使用 BaoStock；如字段不足，再使用 AKShare 公开接口补充；
2. 不绕过任何反爬、登录、验证码或付费限制；
3. 标的池写入 config/universe.yaml；
4. 默认日线、最近 5 年、周度调仓、单边成本 0.03%；

6. 必须检查未来函数；

8. 所有代码要可复现、可测试、可缓存。
```

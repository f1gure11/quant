# 数据合规检查清单

## 可以做

- 使用 BaoStock、交易所公开文件、基金公司公告、本地数据文件；
- 使用 AKShare 的公开接口并控制频率；
- 下载历史数据用于本地研究、论文、课程作业、回测；
- 本地缓存、注明来源、保留下载日期；
- 对结果做研究型报告。

## 不要做

- 绕过验证码、登录、签名、加密参数、App 私有接口、IP 封禁；
- 抓取付费数据、Level-2、会员数据；
- 高频并发请求第三方平台；
- 对外提供原始行情 API、网站、机器人、收费服务；
- 声称数据版权归自己；
- 让策略直接连接券商接口实盘下单。

## 每次新增数据源前必须回答

1. 数据是否公开可访问？
2. 是否需要登录、cookie、token 或会员权限？
3. 是否绕过了验证码、签名、加密参数或反爬？
4. 是否有 robots.txt、用户协议、版权声明限制？
5. 是否会高频访问或影响对方服务器？
6. 是否会对外分发原始数据？
7. 是否有更合规的数据源替代？

若任一答案存在风险，优先改用 BaoStock、本地文件、交易所/基金公司公开数据或正式授权数据。

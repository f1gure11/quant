# Codex 启动提示词：ETF 数据 + 策略 + 回测

请使用 `.agents/skills/quant_data_backtest/SKILL.md` 中的 `quant-data-backtest` 技能，帮我在当前项目中搭建一个合规的 ETF 数据下载、策略生成和回测系统。

要求如下：

1. 数据源优先使用 BaoStock；如 ETF 字段不足，再使用 AKShare 公开接口补充；
2. 不允许绕过验证码、登录、签名、加密接口、App 私有接口、IP 封禁；
3. 不抓取付费数据、Level-2、会员数据；
4. 标的池、时间区间、调仓频率、交易成本写入 `config/universe.yaml`；
5. 默认参数：日线、最近 5 年、周度调仓、单边交易成本 0.03%；
6. 至少实现两个策略：
   - 动量轮动策略；
   - 均线趋势策略；
7. 回测必须避免未来函数：T 日收盘产生信号，T+1 执行；
8. 输出指标：累计收益、年化收益、年化波动、最大回撤、夏普比率、Calmar、胜率、换手率；
9. 输出图表：净值曲线、回撤曲线；
10. 输出报告：`reports/backtest_report.md`；
11. 创建测试：数据完整性检查、未来函数检查、回测资金账务检查；
12. 最终告诉我运行命令、输出路径、策略逻辑、风险与局限。

注意：本项目仅用于学习研究和回测验证，不构成投资建议，不允许生成实盘自动交易或荐股内容。
